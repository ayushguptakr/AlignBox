# Fun Friday Chat App 🎉

A real-time **anonymous group chat** web application inspired by the “Fun Friday Group” UI.  
Built using **Node.js**, **Express**, **Socket.IO**, **MySQL**, and vanilla **HTML/CSS/JS**.

---

## ✨ Features

- 💬 **Real-time chat** powered by Socket.IO  
- 🕶️ **Anonymous toggle** – switch between your name and “Anonymous”  
- 📜 **Persistent messages** stored in MySQL  
- ✅ Messages from you appear aligned to the right  
- Responsive mobile-style UI with incognito icon
